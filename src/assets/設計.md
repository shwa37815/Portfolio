# ポートフォリオ設計書

## 1. 全体アーキテクチャ
本ポートフォリオは、**React + TypeScript** を用いた **SPA (Single Page Application)** として構築する。

* **SPAを採用した理由**:
  * 画面遷移時のページ再読み込み（リロード）をなくし、ネイティブアプリのようにスムーズで高速なユーザー体験（UX）を提供するため。
  * `react-router-dom` を用いて、URLとコンポーネント（画面パーツ）を紐付けて管理する。

## 2. ページ構成（ルーティング）
5つの主要なページ（コンポーネント）に分割し、ユーザーが迷わず情報にアクセスできる王道の構成とする。

1. **ホーム (`/`)**
   * **役割**: サイトの顔となるメインページ。
   * **コンポーネント**: `src/components/pages/Home.tsx`
2. **スキル (`/skills`)**
   * **役割**: 習得済み、および現在学習中の技術スタックを一覧表示する。
   * **コンポーネント**: `src/components/pages/Skills.tsx`
3. **作品 (`/portfolio`)**
   * **役割**: 過去に制作した成果物やミニアプリをギャラリー形式で展示する。
   * **コンポーネント**: `src/components/pages/Portfolio.tsx`
4. **備忘録 (`/memo`)**
   * **役割**: 学習の軌跡をMarkdown形式で表示する。
   * **コンポーネント**: `src/components/pages/Memo.tsx`
5. **コンタクト (`/contact`)**
   * **役割**: GitHubやSNSへのリンク、連絡先を提示する。
   * **コンポーネント**: `src/components/pages/Contact.tsx`

## 3. ディレクトリ（フォルダ）設計
役割ごとにファイルを分割し（関心の分離）、後からコードを追加・修正しやすい構造とする。

## プロジェクト構成

```text
src/
├── App.tsx          # ルーティング（画面遷移）を管理する大元
├── main.tsx         # Reactアプリの起動ファイル
├── components/      # 画面の部品を入れるフォルダ
│   └── pages/       # 1つの画面（ページ）全体を表す
│       ├── Home.tsx       # 最初に表示される画面（タイムライン）
│       ├── PlayGround.tsx # インタラクティブUIの実験場
│       ├── Portfolio.tsx  # 成果物一覧
│       ├── Memo.tsx       # 学習・ナレッジメモ
│       └── Contact.tsx    # お問い合わせ画面
└── assets/          # 画像・ドキュメント等
    ├── memo.md      # プロジェクト構成のメモ
    ├── 関数.md      # React/TSの構文メモ
    └── 設計.md      # 本ドキュメント（設計書）
