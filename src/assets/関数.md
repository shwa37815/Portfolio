## 実装コードの備忘録

### 1. プロジェクトの立ち上げとライブラリ追加
```bash
# 1. Viteを使ったReact+TypeScriptプロジェクトの作成
npm create vite@latest portfolio_1 -- --template react-ts

# 2. 開発サーバーの起動
npm run dev

# 3. 必要な機能の追加インストール
npm install react-router-dom  # SPA（画面遷移）用
npm install react-markdown    # マークダウン表示用
npm install remark-gfm        # ハイライト用ライブラリ

```

## ==========================================
### 開発環境のセットアップ〜GitHub送信コマンド一式〜
## ==========================================

``` bash

# 1. Node.js標準モジュール（fs, child_process等）の型定義を追加
npm install -D @types/node
# 2. Gitリポジトリの初期化
git init
# 3. TypeScriptファイルの翻訳（コンパイル）
npx tsc report.ts
# 4. 翻訳されたJavaScriptの実行（学習記録の自動生成）
node report.js
# 5. 変更の追加とコミット
git add .
git commit -m "feat: CLIによる学習記録自動生成の初期実装"
# 6. ブランチ名を main に統一
git branch -M main
# 7. GitHubリモートリポジトリの登録と初回送信
# ※ <ユーザー名> の部分はご自身のGitHubアカウント名に差し替えてください
git remote add origin https://github.com/<ユーザー名>/AutoCreat_dairy_report.git
git push -u origin main

```
